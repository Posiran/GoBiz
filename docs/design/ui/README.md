# Gobiz UI — نسخه مستقل و اصلاح‌شده

مشکل نسخه قبلی این بود که اگر یک فایل HTML به‌تنهایی از Downloads باز می‌شد، وابستگی آن به `assets/style.css` باعث می‌شد صفحه بدون استایل نمایش داده شود.

در این نسخه CSS و JavaScript داخل خود هر صفحه قرار گرفته‌اند و لوگو نیز inline شده است. بنابراین هر فایل HTML را می‌توان مستقیماً با دوبار کلیک باز کرد.

**شروع پیشنهادی:** `START-HERE.html`

این UI همچنان Prototype است و به Laravel/MySQL متصل نیست.
